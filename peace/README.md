# A little something for Peace

A pink, responsive surprise website. Open `index.html` in a browser; no build or installation is needed.

All three choices show a twinkling night sky and “It’s about to get much better.” After 3.5 seconds the Batman sign appears, stays for 30 seconds, then the entire page goes black. Reload to replay. No mood responses are stored or sent anywhere.

## GitHub Pages

Upload these files to a repository. In its Settings → Pages, select Deploy from a branch, then `main` and `/ (root)`. If uploaded in a `peace` folder of an existing Pages repository, visit its `/peace/` path.

Google Fonts are optional; the page has local serif and sans-serif fallbacks.
